## What Is Readerware

Readerware is a Windows catalog built around a scanner. The classic use is sitting with a stack of books, CDs, or DVDs you already own and letting Readerware barcode catalog punch ISBN or UPC instead of typing. Readerware web lookup then fills the card. Readerware media library is the local file that remains after the session.

The product family thinks in three collections: books, music, and video. That is why a vinyl LP and a hardback do not share one generic “media” row unless you choose to. Collectors who remember CueCat-style wands still look this software up because rapid scanning is the workflow, not cover-art browsing.

Readerware is not a streaming locker and not a tool for listing shop inventory you do not own. Use Readerware rapid entry on copies in the house, a classroom set you administer, or a club library you are allowed to catalog. Leave other people's barcodes out of this database.

## Starting with Readerware

Prerequisites: A PC you administer, a barcode scanner if you have one, and a stack of books or discs you already own.

1. **Prepare:** Test the scanner on a few codes from copies in the room, or plan ISBN typing if no wand is present.
2. **Configure:** Open the matching Readerware media library (books, music, or video) and set which lookup sources you will allow.
3. **Test:** Scan or type three items through Readerware barcode catalog and confirm cards look correct.
4. **Refine:** Adjust Readerware rapid entry so confirmation pauses match how careful you want to be on first pass.
5. **Apply:** Work the rest of the pile. Use Readerware web lookup only for items you actually hold.
6. **Maintain:** Add new purchases the day they arrive, and delete cards when a copy leaves the house.
